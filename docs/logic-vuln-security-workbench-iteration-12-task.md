## 1. 本轮目标

上一轮已经补齐了结构化活动记录，但复盘页仍然是：

- 上面一段系统活动
- 下面一段人工备注

这种展示方式仍然是割裂的，不利于从时间顺序复盘一个案件。

因此本轮目标是：

`把系统活动和人工备注合并成统一案件时间线，并补活动类型筛选。`

---

## 2. 本轮实现

### 2.1 统一时间线

复盘页现在会把：

- 系统活动
- 人工备注

合并成一条按时间倒序排列的案件时间线。

每条时间线记录都会明确展示：

- 来源：系统活动 / 人工备注
- 类型标签
- 标题
- 作者
- 时间
- 正文

系统活动仍然保留 `before/after` 结构化状态块。

### 2.2 活动类型筛选

时间线新增了筛选器，支持：

- 全部时间线
- 仅系统活动
- 仅人工备注
- 仅执行草案
- 仅回写漏洞
- 仅按建议回写
- 各类备注类型

这样复盘时可以直接收敛到某一类关键动作，而不需要在整条时间线里手翻。

### 2.3 备注输入保留

本轮没有改变复盘备注录入方式，仍然保留原有的：

- 备注类型选择
- 文本输入
- 新增备注

只是把“看记录”的部分收敛成了统一时间线。

---

## 3. 当前收益

这一轮完成后，安全工作台的复盘视图更接近真正的案件调查体验：

1. 系统动作和人工判断在同一条时间线上
2. 案件复盘不再需要在两段列表之间来回跳
3. 能按活动类型快速收敛到关键节点

---

## 4. 当前限制

这一轮仍然保持轻量：

1. 筛选器还是单选，不支持多条件组合
2. 时间线还没有聚合成更完整的案件时间轴
3. 活动和备注还没有支持全文搜索

---

## 5. 下一轮建议

如果继续推进，下一轮最值得做的是：

1. 为案件时间线补搜索和类型组合过滤
2. 把执行结果摘要直接挂到时间线节点上
3. 在时间线里增加“跳转到证据 / 跳转到草案 / 跳转到执行结果”的交叉入口
